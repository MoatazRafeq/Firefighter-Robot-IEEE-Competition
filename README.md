#  Firefighter Robot (Autonomous & Manual Control)
**IEEE Robotics Competition Project**

A mobile firefighting robot capable of operating in both **autonomous** and **manual** modes, designed to detect and extinguish fire sources efficiently in simulated emergency environments.

---

##  Project Overview
This project presents a **Firefighter Robot** developed for robotics competitions, combining **autonomous navigation**, **manual remote control**, and **fire detection mechanisms**.

The robot is designed to autonomously search for fire sources, navigate safely through the environment, and activate a firefighting mechanism, while also allowing full manual control when required.

---

##  Achievements
-  **2nd Place – Firefighter Robot (Manual & Autonomous)**  
  **IEEE Robotics Competition**

---

##  Project Objectives
- Detect fire sources using sensors
- Navigate autonomously while avoiding obstacles
- Provide manual override control
- Extinguish fire efficiently
- Demonstrate reliable real‑time control

---

##  System Features

###  Robot Modes
- **Autonomous Mode**
  - Automatic navigation
  - Fire detection
  - Automatic firefighting response

- **Manual Mode**
  - User‑controlled movement
  - Direct control via controller / application

---

##  Hardware Components
- Microcontroller (Arduino)
- Flame Sensors
- Ultrasonic Sensors
- DC Motors & Motor Driver
- Water Pump / Fan System
- Servo Motors
- Mechanical chassis 

---

##  System Logic
1. Scan environment for fire
2. Detect flame intensity & direction
3. Navigate toward the fire source
4. Activate firefighting mechanism
5. Stop operation once fire is extinguished
6. Allow instant manual takeover if required
